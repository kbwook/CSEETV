📱 CSEETV 설치 및 사용 가이드

안드로이드 스마트폰을 실시간 웹 CCTV 및 자동 순환 녹화 블랙박스로 활용하는 설치 방법과 기능별 사용 설명서입니다.

📦 CSEETV.apk 바로 다운로드

1. 앱 다운로드 및 설치 방법

  1. CCTV 카메라로 사용할 안드로이드 스마트폰에서 상단 [📦 CSEETV.apk 바로 다운로드] 버튼을 눌러 APK 파일을 다운로드합니다.
  2. 다운로드가 완료되면 알림창 또는 내 파일(Download 폴더)에서 CSEETV.apk를 눌러 설치를 진행합니다.
  3. 최초 설치 시 "보안을 위해 이 출처의 알 수 없는 앱을 설치할 수 없습니다" 안내가 표시되면 [설정] → [이 출처 허용]을 켠 뒤 설치를 완료합니다.
  4. 앱을 실행하고 [CSEETV 웹서버 시작하기]를 누른 뒤, 카메라 권한과 알림 권한을 모두 허용합니다.
💡 설치 팁: 시청할 PC나 다른 스마트폰에는 별도의 앱을 설치할 필요가 없습니다. 크롬(Chrome), 사파리(Safari), 엣지(Edge) 등 기본 웹 브라우저만 있으면 바로 접속할 수 있습니다.

2. CCTV 화면 접속 방법 (내부 Wi-Fi & 외부 원격 접속)

앱에서 [CSEETV 웹서버 시작하기] 버튼을 누르면 상단 카드에 현재 접속 가능한 주소와 QR 코드가 표시됩니다.

방법 A. QR 코드 스캔으로 즉시 접속 (가장 간편)

  • CCTV 스마트폰 화면 중앙에 표시된 QR 코드를 시청할 스마트폰이나 태블릿의 기본 카메라 앱으로 비추면 접속 링크가 나타나며, 터치 즉시 CCTV 웹 콘솔이 열립니다.

방법 B. 집/사무실 내부 (같은 Wi-Fi 공유기)에서 접속

  • 동일한 Wi-Fi에 연결된 PC나 스마트폰 브라우저 주소창에 앱 상단의 첫 번째 파란색 주소(예: http://192.168.0.15:8080)를 입력합니다.

방법 C. 집 밖 외부(LTE / 5G / 타 지역)에서 접속

  • 1순위 (UPnP 다이렉트 직결): 공유기가 UPnP를 지원하는 경우 앱 화면에 초록색 다이렉트(UPnP): http://공인IP:포트 주소가 자동으로 생성됩니다. 이 주소로 접속하면 1:1로 가장 빠르게 연결됩니다.
  • 2순위 (Hybrid Gateway 접속): UPnP 동작에 문제가 있는 공유기 환경을 위해 기본 제공되는 Hybrid Gateway 주소(예: http://kbwook.familyds.com:9080/cam/cam-xxxx/)로 접속하면, 공유기 환경에 맞춰 1:1 직결 또는 게이트웨이 터널로 자동 연결됩니다.
  • 여러 대의 카메라 사용 시: 각 스마트폰마다 고유한 카메라 ID(예: cam-a3f1)가 자동 생성되며, 만약 여러 기기에 같은 이름을 입력하더라도 자동으로 -2, -3 번호가 부여되어 충돌 없이 모두 사용할 수 있습니다.

3. 비밀번호(접속 PIN) 및 보안 설정

설정 항목 역할 및 사용 방법
접속 PIN
(포트 및 접속 보안 설정 카드)		 내 카메라 영상을 다른 사람이 볼 수 없도록 잠그는 시청자용 비밀번호입니다.
PIN을 입력해 두면 웹 브라우저로 접속했을 때 해당 PIN 번호를 입력해야만 영상 시청 및 원격 제어가 가능합니다.
고유 카메라 ID
(하이브리드 외부 접속 카드)		 외부에서 내 카메라를 구분하는 고유 이름입니다 (예: cam-a3f1, livingroom 등).
앱 최초 설치 시 기기마다 겹치지 않는 고유 ID가 자동 설정됩니다.
터널 보안키 (선택)
(하이브리드 외부 접속 카드)		 개인 전용 Hybrid Gateway 서버를 별도로 구축해 사용할 때 허가된 스마트폰만 등록되도록 제한하는 서버 등록 키입니다. 일반 사용 시에는 비워두시면 됩니다.

4. 주요 기능 사용 방법 (스마트폰 앱 & 웹 브라우저 콘솔)

① 원격 CCTV 동작 시작 / 일시 중지 (Start / Stop)

  • 외출 중에만 카메라를 켜고 집에 있을 때는 카메라를 꺼두고 싶다면, 웹 브라우저 콘솔 상단의 [⏹️ CCTV 동작 중지 (Stop)] 버튼을 누릅니다.
  • 중지 상태(Standby)에서는 카메라 센서·스트리밍·녹화가 모두 꺼져 배터리와 발열을 절약하며, 언제든 웹 브라우저에서 [▶️ CCTV 시작 (Start)]을 눌러 다시 켤 수 있습니다.

② 동영상 자동 분할 저장 및 순환 녹화 (블랙박스 모드)

  • [자동 동영상 저장 (순환 녹화)] 스위치를 켜면 실시간 스트리밍과 동시에 스마트폰 내부에 고화질 .mp4 동영상을 자동 녹화합니다.
  • 저장 시간 단위: 파일 1개당 길이를 1분 / 3분 / 5분 / 10분 / 15분 / 30분 / 60분 중에서 선택할 수 있습니다.
  • 최대 저장 용량 한도: 500MB / 1GB / 2GB / 5GB / 10GB / 20GB 중 원하는 용량을 지정하면, 한도에 도달했을 때 가장 오래된 녹화 파일부터 자동으로 삭제하며 끊김 없이 새 영상을 계속 저장합니다.
  • 저장된 영상은 웹 브라우저의 [📼 저장된 동영상 목록]에서 즉시 재생(구간 이동 지원)하거나 PC/스마트폰으로 다운로드할 수 있습니다.

③ 원격 카메라 제어 및 실시간 동작 감지 (Motion Detection)

  • 웹 브라우저에서 전/후면 렌즈 전환, 플래시(조명) 켜기/끄기, 90° 화면 회전, 좌우 반전, 해상도(480p / 720p / 1080p) 및 디지털 줌(1.0x ~ 5.0x)을 실시간으로 조작할 수 있습니다.
  • 실시간 동작 감지를 켜두면 화면 내 움직임이 포착될 때마다 경고 배지가 켜지고 감지 순간의 스냅샷 사진이 자동으로 기록됩니다.

④ 24시간 장시간 설치를 위한 OLED 블랙 스크린 절전 모드

  • CCTV 스마트폰 화면을 계속 켜두어 발생하는 발열과 번인을 막으려면 앱 또는 웹 콘솔에서 [📱 블랙 스크린 모드]를 켭니다.
  • 스마트폰 화면이 완전히 검은색(밝기 1%)으로 전환되며, 스마트폰 화면을 빠르게 두 번 탭(Double Tap)하면 원래 설정 화면으로 돌아옵니다.
